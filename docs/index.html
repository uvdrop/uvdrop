機能

ポータルや Git 連携なし。ローカルの Python アプリを安全に起動することに絞っています。

  • Drop & Run

    決まった階層の pyproject.toml があるフォルダ、または ZIP を選ぶと uv sync → uv run。

  • 専用 .env

    アプリ本体の外（AppData）に .env を保持し、起動前にワークスペースへコピーします。

  • 保持 / 一時実行

    保持は再起動とショートカット向き。一時実行はプロセス終了後にワークスペース・venv・.env を削除します。

  • ローカルポリシー

    許可パッケージ・許可 Python バージョンを JSON でオフライン管理。xlsx URL 配信も可。

  • OSV オプション

    設定で有効化すると OSV.dev の MAL-* を照会（warn / block）。

  • デスクトップショートカット

    保持したアプリを Windows デスクトップから再起動できます。

使い方

  1. 開発実行 
    git clone https://github.com/uvdrop/uvdrop.git
cd uvdrop
python -m uvdrop
  2. uv の配置

    PATH の uv、または resources/tools/windows-x64/uv.exe に公式バイナリを置きます。

  3. アプリを渡す

    GUI でフォルダ / ZIP を選択。「起動後も保持する」をオフにすると一時実行になります。

  4. ポリシー

    初回起動で %LOCALAPPDATA%\uvdrop\policies\ に例がコピーされます。編集するか、設定から xlsx URL / OSV を有効化。

  5. CLI 
    python -m uvdrop --cli path\to\app
python -m uvdrop --cli path\to\app.zip --temp
python -m uvdrop --version

運営・データ配置

インストールや監査で見る場所はここです。

パス内容
%LOCALAPPDATA%\uvdrop\apps\展開・コピーしたワークスペース
%LOCALAPPDATA%\uvdrop\envs\アプリごとの venv（uv）
%LOCALAPPDATA%\uvdrop\dotenv\専用 .env の正本
%LOCALAPPDATA%\uvdrop\policies\allowlist / python-versions / xlsx キャッシュ
%LOCALAPPDATA%\uvdrop\settings.jsonOSV・xlsx URL など
%LOCALAPPDATA%\uvdrop\apps.json保持アプリのレジストリ

ポリシーの優先

  1. ローカル allowlist.json
  2. xlsx URL から同期したキャッシュ（設定有効時）
  3. 任意で OSV 脅威チェック

Setup.exe の作り方

Inno Setup 未経験向けの手順はリポジトリの installer/PACKAGING.md にまとめています。build.ps1 一発で PyInstaller → Setup.exe まで行けます。
