Features

Start local Python apps with a clear look before anything is installed. Shared catalogs help teams open the same apps without scanning folders.

  • Drop & Run

    Pick a folder or ZIP that has a pyproject.toml in the expected place.

  • Shared catalogs

    Register catalog files or HTTP API endpoints. Open listed apps with the same review / allow / block guards.

  • Dedicated settings file

    Keeps a .env outside the app and copies it into the workspace just before launch.

  • Review before running

    Before creating a virtual environment, review packages that come along (the full resolved set).

  • Allow list / block list

    Manage package names and version rules in a grid. Import from Excel / CSV offline.

  • Console window (optional)

    The black console window is hidden by default.

  • Usage history

    Last launch, launch counts, and day / week / month charts.

  • Venv hibernation

    Keep the app entry and settings while removing only its venv. Rebuild later from the uv global cache.

  • Display language

    Switch Japanese / English / Chinese inside the app.

  • Desktop shortcuts

    Relaunch kept apps from the Windows desktop.

Built as a small-org portal

Manage apps as uv-ready folders, publish a catalog, and let people pick and run — with the same package and Python checks every time.

  • Catalog, not folder scan

    Only apps listed in the catalog appear. Admins decide what is offered; users open from the list.

  • Versions & allow / block

    Review the full dependency tree, enforce package allow / block rules, and warn on Python support windows.

  • Try on a local folder

    Win11 demo pack under examples/local-portal/ — no UNC share required. Optional local HTTP catalog script included.

Speed expectations

Day-to-day speed is mostly the warm uv cache. First download on a new PC is much slower. See docs/BENCHMARK.md.

  • Warm cache

    After packages are cached once, light / medium stacks often sync and start in seconds to low tens of seconds.

  • Cold / first PC

    Network-bound. A light-tier pass can take many minutes; heavy wheels (torch / TF / …) can take tens of minutes.

  • Hibernate stays fast

    Removing a venv keeps the global uv cache, so rebuilds usually feel closer to warm than to cold.

Shared catalogs

A catalog is a table of contents for team apps. Folders are never auto-scanned. See docs/CATALOG.md.

  1. Publish a catalog

    Put apps on a share, then write a catalog JSON (name, summary, path, optional command).

  2. File or API endpoint

    Serve it as a local/UNC file or any HTTP(S) API that returns the same JSON. A .json suffix is not required.

  3. Register in Settings

    Settings → Catalogs → add a file path or endpoint URL (multiple catalogs OK).

  4. Open from catalog

    Main screen → Open from catalog → pick an app. Path access, required-file checks, and review dialogs still run.

Usage

  1. Run from source 
    git clone https://github.com/uvdrop/uvdrop.git
cd uvdrop
python -m uvdrop
  2. Where uv lives

    Use uv on PATH, or place the official binary at resources/tools/windows-x64/uv.exe. Prefer 0.11.6+. Upgrade: docs/UV_RUNTIME.md.

  3. Hand over an app

    In the GUI, pick a folder, ZIP, or Open from catalog. After review before running, it stays in the list until you delete it.

  4. Register catalogs

    In Settings → Catalogs, add shared catalog files or HTTP API endpoints. Details: docs/CATALOG.md.

  5. Allow list and related settings

    On first launch, samples are copied to %LOCALAPPDATA%\uvdrop\policies\.

  6. Command line 
    python -m uvdrop --cli path\to\app
python -m uvdrop --cli path\to\app.zip --temp
python -m uvdrop --version

Ops & where data lives

These are the paths to check for install or audit.

Path What it holds
%LOCALAPPDATA%\uvdrop\apps\Copied / extracted workspaces
%LOCALAPPDATA%\uvdrop\envs\Per-app virtual environments (uv)
%LOCALAPPDATA%\uvdrop\dotenv\Canonical .env files
%LOCALAPPDATA%\uvdrop\policies\Allow list / block list / Python versions / Excel cache
%LOCALAPPDATA%\uvdrop\settings.jsonAllow & block lists, catalogs, Excel / CSV, proxy, and other settings
%LOCALAPPDATA%\uvdrop\apps.jsonRegistry of kept apps
%LOCALAPPDATA%\uvdrop\usage.jsonLaunch history (by day)

Policy order

  1. Local allow / block lists, or direct input in settings
  2. Cache imported from Excel / CSV (when enabled)
  3. Allowed Python version check
